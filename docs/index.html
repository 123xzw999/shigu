关于准确率，说清楚

这一节不好看，但你应该知道

转折判断的准确率是 30% 左右，不是 80%。
16 个板块 × 日/周 × 双向，49 个可信组合的样本外命中率平均 29.8%，最高 53.3%； 随机基线约 6~9%。它比瞎猜好 3.5~6 倍，但远谈不上「精准预测」。
那它有什么用？看盈亏比。信号出现后 30 个交易日的最大浮盈中位数： 底部信号 24.8%（随机位置只有 7.4%），顶部信号 16.8%（随机 6.6%）。

翻译成人话：它没法告诉你哪一根是最低点，但能告诉你现在是不是比瞎买好得多的位置。 交易上这就够了 —— 你不需要买在最低那一根。

所以界面上每行都给两个数字：概率（绝对）+ 分位（相对）。优先看分位 —— 绝对阈值是在某段历史上标定的，换一段时间概率分布就漂了。

常见问题

安装时提示「解析包错误」或装不上

多半是下载不完整（微信 / QQ 内置浏览器会截断）。用系统浏览器重新下载。 APK 只打了 arm64-v8a，2018 年后的机型基本都是这个架构。

打开后黑屏 / 一直转圈

首次启动要在本地起服务并拉数据，等 5 秒。超过 15 秒还黑， 大概率是网络问题（新浪接口被限制）。切到 4G / 5G 再试。

为什么不能像网页一样直接打开？

因为新浪的行情接口会校验 Referer，浏览器发不了自定义 Referer， 从任何网站发起的请求都会被返回 Forbidden。 所以抓取必须在本地 Python 里做 —— 这就是为什么静态托管跑不起来，必须装 App。

APK 装不上，还有别的办法吗？

有，用 Termux（安卓上的 Linux 终端）跑同一套代码，功能完全一样：
① 装 Termux（从 F-Droid 或 GitHub 下载，别用应用商店的老版本）
② 下载 shigu-termux.zip，解压到 Termux 主目录
③ 执行 bash ~/jyhqs/termux/install.sh，装完再执行 bash ~/jyhqs/termux/start.sh
④ 浏览器打开 http://127.0.0.1:8765
好处是能改代码、能跑命令行版；坏处是要敲几条命令。

数据是实时的吗？

行情 5 秒一轮，深度分析（K线 + 缠论 + 筹码 + 转折判断）30 秒一轮。 数据源是新浪财经免费接口，有几分钟延迟属于正常。

要不要登录 / 会不会上传我的数据

不用登录，也没有服务器。所有抓取和分析都在你手机本地完成， 自选股存在本地，不上传任何东西。

电脑上怎么用？

电脑版还是双击 启动.bat，浏览器自动打开。 源码在 GitHub， 纯 Python 标准库 + 原生 JS，零第三方依赖。
