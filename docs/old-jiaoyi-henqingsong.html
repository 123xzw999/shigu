缠论

K线包含处理 → 分型 → 笔（老笔标准）→ 线段（特征序列）→ 中枢 → 背驰 → 一二三买卖点。 不是画几条折线，是真按原文口径算的。

筹码分布（核心）

CYQ 三角分布 + 换手衰减 + 主力/散户双层模型。两层用不同尖锐度的分布核： 主力集中在均价、散户铺满区间，再配合位置权重，两个分布才能在价格上分开。

主力集中区 · 散户集中区 · POC · 价值区
🏭

主力行为

威科夫六阶段（吸筹/洗盘/拉升/派发/下跌/横盘）软打分 + softmax， 并把历史切成片段，算出每个阶段的成交量加权成本。

避免硬阈值导致阶段跳变
💼

基金：主动 vs 被动

两类基金优劣标准完全不同：被动看跟踪误差，主动看 Jensen Alpha / 信息比率。 还会反推「这只基金到底有多主动」，主动产品相关性 0.98 直接提示「伪主动」。

11 个行业基准自动匹配
🌍

外围市场 + GRAI

美股/港股/日经/外汇/商品 31 个标的，压成一个 全球风险偏好指数： 美股 +0.34、恒生 +0.20、美元人民币 -0.16、黄金 -0.10……并给出对 A 股的传导判断。

TRS 趋势共振评分

七个维度各自 tanh 软饱和到 [-1,1] 再加权。为什么不用线性求和？ 因为 RSI 能到 90、MACD 柱能很大，线性相加会让某个维度吞掉其他所有维度。

几个关键设计

筹码双层分离
m_t = 0.5 + 0.42·tanh(0.9(vr-1) + 5r + 1.8(0.5-p))
低位放量上涨 → 主力吸筹占比高；高位放量下跌 → 主力派发。 两层各自衰减，且用不同 sharp 的三角核（主力 1.85 / 散户 0.42）， 这样即使比例相同，分布形状也不同。
GRAI
100·tanh(Σ wᵢ·(涨跌幅ᵢ/典型日波动ᵢ) + 0.15·(美股52周分位-0.5)·2)
每个市场按自己的波动特性标准化，避免纳指跌 1% 和人民币跌 0.1% 被等权对待。
TRS 评分
S = 100·tanh(2.2·ΣwᵢDᵢ/Σwᵢ)，Dᵢ ∈ [-1,1]
软饱和等价于「温和的软阈值」——小值区近似线性、大值区饱和。 指数/场外基金缺筹码时，该维度权重自动让给其他维度。
基金绝对收益约束
相对基准再好，只要还在亏钱就不能算「良好」： 年化收益为负时按 max(0.25, 1 + 年化/10) 打折。
